⚠ Важная особенность этого кода

break завершает только ближайший цикл for, но не цикл while. После победы программа снова проверит action != 'off'. Так как новое значение action нигде не вводится, при action = 'game' внешний цикл будет продолжаться бесконечно.

Как программа может завершиться?

Только если самое первое значение action равно строго 'off'. Если ввести другое слово, условие if action == 'game' не выполнится, а while начнёт повторяться без новых запросов ввода.
